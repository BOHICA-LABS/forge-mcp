# ADV-P1-018 — Holdout set misses malformed/incomplete transport-frame capture scenarios

**Severity:** MEDIUM  
**Category:** missing-edge-case  
**Affected artifacts:** BC-4.09.001, HS-INDEX

## Description
BC-4.09.001 explicitly covers malformed JSON, batch messages, and connection drops mid-message with partial-frame capture. The holdout index contains crash, rate, pagination, and concurrency scenarios, but nothing targeting partial frame capture, mixed malformed traffic, or recovery from truncated HTTP/SSE bodies. That leaves one of the trickier capture invariants completely unchallenged in holdout evaluation.

## Proposed Resolution
Add a holdout scenario for malformed/truncated traffic across transports, including partial JSON-RPC frames, invalid JSON, and mid-stream disconnects, with expected capture and UI degradation behavior.
