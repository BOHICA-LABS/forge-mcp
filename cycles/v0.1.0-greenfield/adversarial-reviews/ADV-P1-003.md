# ADV-P1-003 — Security audit suppression UX contradicts suppression contract

**Severity:** HIGH  
**Category:** ux-inconsistency  
**Affected artifacts:** BC-7.18.002, FLOW-005

## Description
BC-7.18.002 requires suppression to be an overlay: suppressed findings remain in the report with `suppressed: true` and unchanged content. FLOW-005 says that after pressing `u`, the finding is “removed from default view” and the “success path” repeats that suppressed findings are “gone from default list.” That is not just a view concern; it changes operator expectations and creates a discoverability hole for audit evidence. The contract never specifies where suppressed findings remain visible in TUI, how to inspect them, or whether export defaults include them.

## Proposed Resolution
Define suppression rendering consistently across BC-7.18.002 and FLOW-005: suppressed findings must remain exportable and inspectable, default list filtering behavior must be explicit, and the UI should show a visible suppressed filter/state toggle rather than silently disappearing findings.
