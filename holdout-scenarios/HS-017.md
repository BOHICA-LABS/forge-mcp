# HS-017 — TUI with minimal terminal (80×24, 16-color, no Unicode)

## Description

A developer launches Forge MCP's TUI on a bare-minimum terminal environment:
80 columns × 24 rows, 16-color palette (no 256-color or truecolor), and no Unicode
support (ASCII-only). This is common on remote SSH sessions, CI terminal logs, older
terminal emulators, and screen readers. All TUI features must remain accessible via
keyboard, no information should be conveyed through color alone, and the layout must
collapse gracefully to fit the constrained viewport.

This tests accessibility and graceful degradation of the TUI — ensuring it's usable
in the worst-case terminal environment.

## Setup

1. Configure a terminal emulator with:
   - Size: 80×24 (classic VT100 dimensions)
   - Color: 16-color mode (TERM=xterm)
   - Unicode: disabled (LANG=C or LANG=en_US.ASCII)
   - Alternatively: `TERM=dumb` for absolute minimum
2. Start a mock MCP server with 3 tools and active notification stream
3. Connect to the server

## Steps

1. Set terminal to 80×24, 16-color, ASCII-only
2. Launch `forge-mcp tui`
3. Verify the TUI renders without visual corruption
4. Navigate through all major panels using keyboard only:
   - Server list / connection panel
   - Tool inspector
   - Traffic inspector
   - Logs panel
5. Connect to the mock server
6. Inspect a tool's schema
7. View live traffic
8. Verify no information is lost due to:
   - Color-only indicators (must have text/symbol alternatives)
   - Unicode-only characters (must have ASCII fallbacks)
   - Viewport overflow (must scroll or collapse, not truncate invisibly)
9. Resize terminal to 60×20 (below minimum) and observe behavior
10. Test all keyboard shortcuts listed in help

## Expected Behavior

### Layout
- TUI renders a usable layout at 80×24
- Panes collapse to single-pane mode if needed (tab-switching between panels)
- No horizontal overflow or invisible truncation
- Status bar is visible with essential info (connection status, server name)
- Scrolling works for lists that exceed the viewport

### Color
- 16-color mode renders without errors or invisible text
- All status indicators have non-color alternatives:
  - Connected: `[OK]` or `✓` (or `*` in ASCII) + green
  - Error: `[ERR]` or `!` + red
  - Warning: `[WARN]` or `?` + yellow
- No information is conveyed through color alone

### Unicode
- In ASCII-only mode, all box-drawing characters fall back to `-`, `|`, `+`
- All status icons have ASCII alternatives
- Tool names, descriptions, and data are displayed correctly (they're ASCII)
- No mojibake or rendering artifacts

### Keyboard
- All features accessible without mouse
- Help screen (`?` or F1) lists all shortcuts
- Tab/Shift+Tab cycles through panels
- Arrow keys navigate within panels
- Enter selects / inspects
- Escape goes back
- `q` quits

### Graceful Degradation
- At 60×20 (below recommended minimum):
  - TUI either adapts (single-pane mode) or
  - Shows a clear message: "Terminal too small: need 80×24, have 60×20"
  - Does NOT crash or render garbage

## Must-Pass Criteria

1. TUI renders without corruption at 80×24 with 16 colors
2. All features accessible via keyboard (no mouse-only actions)
3. No color-only information indicators (all have text/symbol alternatives)
4. ASCII fallbacks work when Unicode is unavailable
5. TUI does not crash on undersized terminal (handles gracefully)

## Satisfaction Scoring Rubric

| Criterion | 0 | 1 | 2 | 3 |
|-----------|---|---|---|---|
| Layout at 80×24 | Unusable / corrupted | Renders but overflow/truncation | Usable single-pane mode | Multi-pane or clean tab-switching layout |
| Color degradation | Invisible text / crashes | Some elements unreadable | All readable, minor ugliness | Clean 16-color palette, attractive |
| Unicode fallback | Mojibake / rendering errors | Partial fallback, some artifacts | Complete ASCII fallback, functional | Clean ASCII rendering, no visual glitches |
| Keyboard accessibility | Must use mouse for some actions | Most actions keyboard-accessible | All actions keyboard-accessible | All accessible + discoverable help screen |
| Undersized terminal | Crash or hang | Garbage rendering | Degrades but somewhat usable | Clear message or adaptive single-pane |
