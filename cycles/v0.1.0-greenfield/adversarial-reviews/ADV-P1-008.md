# ADV-P1-008 — Security audit input/response scope is inconsistent across contracts

**Severity:** MEDIUM  
**Category:** contradiction  
**Affected artifacts:** BC-7.16.002, BC-7.17.002

## Description
BC-7.16.002 says SSRF detection scans tool responses only and explicitly excludes tool input URLs. BC-7.17.002 says root enforcement checks both tool arguments and responses. FLOW-005 prerequisite text says the auditor analyzes “actual arguments passed to tools” for SSRF. So which is it? The flow says inputs matter, the SSRF contract says they do not, and root enforcement already assumes input inspection exists.

## Proposed Resolution
Unify the audit data model. Either extend BC-7.16.002 to inspect both arguments and responses, or explicitly split “input-side SSRF risk” into a separate BC with distinct severity/confidence rules. Update FLOW-005 to match.
