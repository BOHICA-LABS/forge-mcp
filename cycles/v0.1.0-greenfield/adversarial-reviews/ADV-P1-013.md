# ADV-P1-013 — Sampling proxy logs can capture prompt and tool-call secrets with no redaction policy

**Severity:** HIGH  
**Category:** security-blind-spot  
**Affected artifacts:** BC-2.05.004, BC-4.09.001

## Description
BC-2.05.004 requires the full sampling request/response to be logged in the traffic inspector. BC-4.09.001 requires byte-identical raw capture of all messages. Combined, this creates an obvious secret-exposure path for prompts, auth-bearing tool outputs, model responses, and potentially LLM provider metadata. The spec includes zero redaction, access-control, or opt-out policy for this especially sensitive message class.

## Proposed Resolution
Define a capture-sensitivity policy for sampling and auth-bearing traffic: redacted presentation while preserving raw bytes only in protected storage, explicit opt-in for full content visibility, or per-message sensitivity tagging with UI masking and export controls.
