# ADV-P1-009 — Traffic replay UX omits explicit target designation required by contract

**Severity:** MEDIUM  
**Category:** ux-inconsistency  
**Affected artifacts:** FLOW-003, BC-4.10.003

## Description
BC-4.10.003 makes explicit target designation a hard invariant: replay must never default to the original server and requires deliberate user confirmation. FLOW-003 says the user presses `R` on a selected message and the request is replayed to “the server,” with no target-selection dialog, no prior target state, and no confirmation step. That is a direct UX/spec mismatch on a safety-sensitive action.

## Proposed Resolution
Add replay target selection and confirmation to the traffic inspector flow and screen spec. The `R` key should either open a target picker or only operate when a prior explicit replay target is visibly set.
