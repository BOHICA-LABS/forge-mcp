# ADV-P1-001 — Streamable HTTP contract uses deprecated SSE endpoint example

**Severity:** HIGH  
**Category:** protocol-error  
**Affected artifacts:** BC-1.02.002, domain-research.md §1.3

## Description
BC-1.02.002 states Forge supports Streamable HTTP and explicitly forbids deprecated SSE transport, but its canonical happy-path vector uses `url: "https://mcp.example.com/sse"`. The domain research says 2025-11-25 Streamable HTTP uses a single MCP endpoint with POST and optional GET for SSE stream establishment, replacing the old HTTP+SSE endpoint model. Using `/sse` as the normative example bakes the deprecated transport shape directly into the transport contract.

## Proposed Resolution
Replace the example URL with a neutral Streamable HTTP endpoint such as `https://mcp.example.com/mcp` and add an explicit note that `/sse`-style legacy endpoints are non-compliant unless they expose the 2025-11-25 single-endpoint Streamable HTTP semantics.
