# SR-004: Explicitly Define Behavior for Missing Schemas

## Severity: LOW
## Category: clarity
## Location: BC-1.01.002, EC-003

## Description
EC-003 handles the case where a config file is valid JSON but lacks both `mcpServers` and `servers` keys. The expected behavior is to "Return empty server list for that file with warning `E-CFG-004: No recognized schema`." While correct, it could be slightly clearer if it explicitly states whether processing continues to other config files.

## Suggestion
Update the expected behavior for EC-003 to explicitly state: "Return empty server list for that file with warning `E-CFG-004: No recognized schema`. Processing continues for other discovered config files." This aligns with the behavior described in EC-002 for invalid JSON.
