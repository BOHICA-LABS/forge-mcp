# ADV-P1-017 — Root enforcement assumes path-like schema fields can be identified reliably

**Severity:** MEDIUM  
**Category:** implicit-assumption  
**Affected artifacts:** BC-7.17.002, domain-research.md

## Description
BC-7.17.002 says Forge inspects “inputSchema fields of type string that represent paths,” but never defines how path-like fields are identified. JSON Schema `type: string` does not magically tell you whether a field is a file path, URL, shell snippet, or user label. The entire root-enforcement scheme quietly assumes conventions or annotations that are never specified.

## Proposed Resolution
Specify the path-identification strategy: schema `format`, field-name heuristics, tool annotations, or explicit allowlists. If none exist, downgrade this check to best-effort and document expected false negatives.
