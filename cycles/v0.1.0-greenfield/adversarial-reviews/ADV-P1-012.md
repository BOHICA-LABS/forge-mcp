# ADV-P1-012 — TUI pane model conflicts with full-tab screens added later in UX spec

**Severity:** MEDIUM  
**Category:** ambiguity  
**Affected artifacts:** BC-3.06.001, FLOW-005, SCR-008

## Description
BC-3.06.001 defines a five-region dashboard with server browser, capability explorer, traffic inspector, health metrics, and status bar. The UX spec later introduces full content-area tabs such as Security Audit and Conformance Runner. The spec never reconciles whether these are overlays, dedicated tabs replacing center panes, or separate modes. That means keyboard focus, pane persistence, and layout collapse rules are underspecified.

## Proposed Resolution
Revise BC-3.06.001 and the UX index/screens to define the top-level navigation model: persistent five-pane dashboard with modal/full-pane views, or tabbed content areas within the dashboard shell. Then specify how focus and hidden panes behave.
