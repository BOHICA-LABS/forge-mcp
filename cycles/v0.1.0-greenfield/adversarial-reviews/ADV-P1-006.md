# ADV-P1-006 — No verification property covers suppression overlay integrity

**Severity:** HIGH  
**Category:** verification-gap  
**Affected artifacts:** VP-INDEX, verification-coverage-matrix.md, BC-7.18.002

## Description
BC-7.18.002 makes suppression overlay semantics a hard invariant: original findings must be preserved, unchanged, and merely marked suppressed. That is a security-audit integrity property, yet no VP covers it. The coverage matrix includes confidence bounds and schema drift completeness, but nothing for “suppression never mutates or deletes original findings.” For a CRITICAL security module, that omission is sloppy.

## Proposed Resolution
Add a dedicated VP for suppression overlay integrity in forge-security verifying that suppression preserves finding identity/content, only alters overlay metadata, and does not affect export/report traceability except exit-code contribution.
