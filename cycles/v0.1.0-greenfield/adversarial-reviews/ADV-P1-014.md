# ADV-P1-014 — Behavioral contracts invent error codes not present in taxonomy

**Severity:** MEDIUM  
**Category:** contradiction  
**Affected artifacts:** error-taxonomy.md, BC-1.02.002, BC-2.05.004

## Description
The error taxonomy defines E-CON, E-CFG, E-PRO, E-TUI, E-SEC, E-CAP, and E-MON codes. BC-1.02.002 uses E-CON-009 and E-CON-010 even though the taxonomy only defines E-CON-001 through E-CON-008. BC-2.05.004 introduces E-SMP-001, which is not in the taxonomy at all. Either the taxonomy is incomplete or the contracts are freelancing identifiers.

## Proposed Resolution
Reconcile all BC error references against the taxonomy. Either extend the taxonomy with the missing codes/categories or replace ad hoc identifiers in the BCs with existing registered errors.
