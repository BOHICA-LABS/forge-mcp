# ADV-P1-011 — No formal/property verification for replay safety invariant

**Severity:** MEDIUM  
**Category:** verification-gap  
**Affected artifacts:** BC-4.10.003, VP-INDEX

## Description
BC-4.10.003 elevates “explicit target designation required” to an invariant, but the L4 registry has no VP covering replay state safety. There are VPs for filter ordering and ring buffer bounds, yet nothing for “replay cannot execute without explicit target.” This is the sort of state-machine bug that turns a debugging feature into accidental production mutation.

## Proposed Resolution
Add a replay state-machine VP for forge-traffic proving replay is impossible from the idle state without an explicit target-designated transition and that original-target defaulting cannot occur.
