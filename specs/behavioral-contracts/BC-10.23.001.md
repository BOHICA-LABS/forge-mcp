# BC-10.23.001 — Tool Schema Diff Between Two Servers

## Summary

Connects to two MCP servers and compares their tool definitions. Reports
additions (tools in server B but not A), removals (tools in A but not B),
and changes (same tool name with different schemas, descriptions, or
annotations). Handles pagination for servers with many tools.

## Preconditions

| ID | Condition |
|----|-----------|
| PRE-001 | Both target MCP servers are reachable and have completed initialization |
| PRE-002 | Both servers advertise the `tools` capability |
| PRE-003 | Tool lists have been fully retrieved from both servers (including paginated results) |

## Postconditions

| ID | Condition |
|----|-----------|
| POST-001 | All tools from both servers have been enumerated |
| POST-002 | Tools present in B but not A are reported as "added" |
| POST-003 | Tools present in A but not B are reported as "removed" |
| POST-004 | Tools with the same name but different definitions are reported as "changed" with specific diffs |
| POST-005 | Changes include: description diff, inputSchema diff, annotation diffs (readOnlyHint, destructiveHint, idempotentHint, openWorldHint) |
| POST-006 | Tools identical in both servers are reported as "unchanged" (or omitted in diff-only mode) |

## Invariants

| ID | Invariant |
|----|-----------|
| INV-001 | Tool identity is determined by `name` field |
| INV-002 | Total tools reported = added + removed + changed + unchanged |
| INV-003 | Comparison is directional: A is "baseline", B is "target" (like git diff A B) |
| INV-004 | Pagination is fully exhausted before comparison begins |

## Edge Cases

| ID | Scenario | Expected Behavior | Source |
|----|----------|-------------------|--------|
| EC-001 | Servers use different protocol versions | Comparison proceeds on common tool schema fields; version-specific fields noted | DEC-015 |
| EC-002 | Server A has 0 tools | All tools in B reported as "added" |  |
| EC-003 | Both servers have 0 tools | Empty diff report; no additions, removals, or changes |  |
| EC-004 | Tool has same name but completely different schema | Reported as "changed" with full schema diff |  |
| EC-005 | Server B has paginated tools (> 1 page) | All pages fetched before comparison; pagination cursor followed to completion |  |
| EC-006 | Tool annotation present in A, absent in B | Reported as annotation removal in the diff |  |
| EC-007 | Tool description differs only in whitespace | Reported as "changed" (exact string comparison) or "unchanged" (normalized) — configurable |  |
| EC-008 | One server disconnects during tool listing | Error reported for that server; partial comparison not attempted |  |

## Canonical Test Vectors

### Happy Path

| ID | Server A Tools | Server B Tools | Expected Diff |
|----|----------------|----------------|---------------|
| TV-HP-001 | `[read_file, write_file]` | `[read_file, write_file, delete_file]` | added: `delete_file`; removed: none; changed: none |
| TV-HP-002 | `[search{query:string}]` | `[search{query:string, limit:number}]` | changed: `search` — inputSchema: added property `limit` |
| TV-HP-003 | `[tool_a, tool_b]` | `[tool_a, tool_b]` (identical) | No differences |

### Edge Case

| ID | Server A Tools | Server B Tools | Expected Diff |
|----|----------------|----------------|---------------|
| TV-EC-001 | `[tool_a{readOnlyHint:true}]` | `[tool_a{readOnlyHint:false}]` | changed: `tool_a` — annotation `readOnlyHint`: true → false |
| TV-EC-002 | `[]` (no tools) | `[tool_a, tool_b, tool_c]` | added: `tool_a`, `tool_b`, `tool_c` |
| TV-EC-003 | `[tool_a{destructiveHint:true}]` | `[tool_a]` (no annotations) | changed: `tool_a` — annotation `destructiveHint` removed |

### Error

| ID | Input | Expected Output |
|----|-------|-----------------|
| TV-ERR-001 | Server B does not advertise `tools` capability | Error: "server B does not support tools capability; cannot compare" |
| TV-ERR-002 | Server A disconnects during `tools/list` | Error: "failed to retrieve tools from server A: connection lost" |

## Verification Properties

| ID | Property | Method |
|----|----------|--------|
| VP-001 | All paginated tools are retrieved before comparison | Page count assertion |
| VP-002 | Diff is complete: added + removed + changed + unchanged = total unique tools | Arithmetic invariant check |
| VP-003 | Schema diff identifies all changed fields | Property-based test with generated tool schemas |
| VP-004 | Annotation changes are individually reported | Targeted annotation diff test |
