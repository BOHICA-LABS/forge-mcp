# SR-003: Specify TUI Frame Rate Measurement Method

## Severity: LOW
## Category: test-derivability
## Location: nfr-catalog.md (NFR-002)

## Description
NFR-002 requires a sustained frame rate of ≥ 60fps at 100 events/sec ingest. While the target is clear, the exact method for measuring this frame rate in an automated test environment (CI) is not specified. Testing TUI frame rates can be tricky, often requiring specialized terminal emulators or mock rendering backends.

## Suggestion
Provide guidance on how to derive a test for NFR-002. Suggest using a specific ratatui backend (e.g., `TestBackend`) to count `draw` calls over a fixed time period while feeding a synthetic event stream, rather than relying on actual terminal rendering, which can be inconsistent in CI.
