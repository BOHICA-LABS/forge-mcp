# SR-002: Provide Example Heuristics for Security Rules

## Severity: LOW
## Category: guidance
## Location: prd.md (Section 2.7), nfr-catalog.md (NFR-005)

## Description
The specifications for security auditing (CAP-016, CAP-017) mention detecting dangerous tool patterns, SSRF attempts, and permission escalation. However, there are no concrete examples of what these patterns look like in the context of MCP messages. An implementer might struggle to define the initial set of rules or heuristics to achieve the >80% precision target (NFR-005).

## Suggestion
Provide a small set of canonical examples or a reference guide for security heuristics. For instance, what constitutes an SSRF attempt? (e.g., requesting `169.254.169.254` or `metadata.google.internal`). What constitutes a dangerous tool pattern? (e.g., executing `sh -c` with unsanitized input). This guidance will significantly improve developer experience and ensure the initial implementation meets security goals.
