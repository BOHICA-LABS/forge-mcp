# SR-005: Detail DiscoveredConfig properties

## Severity: LOW
## Category: story-readiness
## Location: BC-1.01.002, PRE-001

## Description
PRE-001 references a `DiscoveredConfig` object provided by BC-1.01.001. However, the structure of this object isn't fully defined in BC-1.01.002. To properly implement the parsing logic, the developer needs to know what information `DiscoveredConfig` contains (e.g., file path, editor type, raw content). This information is necessary to fulfill POST-003 (`source_editor`, `source_path`).

## Suggestion
Either reference the specific part of BC-1.01.001 that defines `DiscoveredConfig` or briefly list its essential properties in the PRE-001 description (e.g., "A `DiscoveredConfig` struct containing `content` (string), `path` (PathBuf), and `editor` (enum)"). This ensures the implementer has all necessary context within the contract.
