# ADV-P1-007 — SSRF detection contract misses DNS rebinding and hostname resolution cases

**Severity:** HIGH  
**Category:** missing-edge-case  
**Affected artifacts:** BC-7.16.002, VP-009

## Description
BC-7.16.002 only scans literal IPs and metadata paths in response text. It never specifies behavior for hostnames resolving to private, loopback, link-local, or metadata addresses, which is one of the standard SSRF evasions. VP-009 doubles down on that narrow scope by proving only raw IPv4 classification. That leaves a glaring blind spot: `http://metadata.internal`, `http://localhost`, or a domain that resolves to 169.254.169.254 bypasses the defined detector.

## Proposed Resolution
Extend BC-7.16.002 to cover hostname-based SSRF indicators and explicit non-goals. If hostname resolution is intentionally out of scope, state that risk and add a holdout scenario. Otherwise add verification/tests for hostname normalization and resolved-address classification, including `localhost` and IPv6 host literals.
