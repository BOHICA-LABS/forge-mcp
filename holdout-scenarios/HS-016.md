# HS-016 — Known-problematic corpus: server with known CVEs

## Description

Forge MCP's security auditor is run against a simulated MCP server that mimics the
behavior pattern of CVE-2025-68145 — a path traversal vulnerability in the Anthropic
Git MCP server that allowed remote code execution through crafted file access outside
the repository root. The simulated server accepts file path arguments and returns
content from outside the declared root directory.

This scenario tests the **false negative rate** of Forge MCP's security auditor.
A tool that fails to detect known vulnerability patterns will leave users exposed to
real threats.

## Setup

1. Create a mock MCP server that simulates the CVE-2025-68145 pattern:
   - Declares a `read_file` tool with `rootDir` parameter
   - Accepts `path` argument intended to be relative to rootDir
   - **Vulnerability:** Does NOT validate that `path` stays within rootDir
   - `read_file(path="../../etc/passwd")` returns actual file contents
   - `read_file(path="../../../.ssh/id_rsa")` returns actual file contents
   - Tool description does NOT mention path traversal (looks benign):
     ```json
     {
       "name": "read_file",
       "description": "Read a file from the repository",
       "inputSchema": {
         "type": "object",
         "properties": {
           "path": { "type": "string", "description": "Relative file path" }
         },
         "required": ["path"]
       }
     }
     ```

2. The server also has a `run_command` tool:
   ```json
   {
     "name": "run_command",
     "description": "Run a git command in the repository",
     "inputSchema": {
       "type": "object",
       "properties": {
         "command": { "type": "string", "description": "Git command to run" }
       },
       "required": ["command"]
     }
   }
   ```
   - **Vulnerability:** Does NOT validate that command starts with "git"
   - `run_command(command="cat /etc/passwd")` succeeds

## Steps

1. Run `forge-mcp connect vuln-server`
2. Run `forge-mcp info vuln-server --json` — inspect tools
3. Run `forge-mcp audit vuln-server --json` — full security audit
4. Check for path traversal detection on `read_file`
5. Check for command injection detection on `run_command`
6. Verify severity levels of detected findings
7. Count false negatives (known vulns not detected)

## Expected Behavior

### Detection Requirements
The security auditor MUST detect:

1. **Path traversal on `read_file`:**
   - Finding: Tool accepts file path without declared root/boundary enforcement
   - Severity: High or Critical
   - Evidence: `path` parameter of type string with no path validation
   - Mapping: AST03 (tool input manipulation)

2. **Command injection on `run_command`:**
   - Finding: Tool accepts arbitrary command strings
   - Severity: Critical
   - Evidence: `command` parameter with no input validation/allowlist
   - Mapping: AST03 (tool input manipulation), potential RCE

### Detection Quality
- Findings should reference the specific tool and parameter
- Remediation suggestions should be specific:
  - `read_file`: "Implement path canonicalization and boundary check"
  - `run_command`: "Use command allowlist, not arbitrary string input"
- Confidence should be high (≥ 0.7) — these are textbook vulnerability patterns

### False Negative Rate
- Target: 0 false negatives for these known patterns
- Both path traversal AND command injection must be flagged
- If either is missed, the false negative rate is unacceptable

## Must-Pass Criteria

1. Path traversal vulnerability on `read_file` is detected
2. Command injection vulnerability on `run_command` is detected
3. Both findings are classified at High or Critical severity
4. The specific tools and parameters are identified in findings
5. Zero false negatives for these known CVE-equivalent patterns

## Satisfaction Scoring Rubric

| Criterion | 0 | 1 | 2 | 3 |
|-----------|---|---|---|---|
| Path traversal detection | Not detected | Detected at low severity | Detected at medium severity | Detected at high/critical with path details |
| Command injection detection | Not detected | Detected at low severity | Detected at medium severity | Detected at critical with RCE implications |
| Tool attribution | No tool identified | Generic findings, no tool names | Correct tools, missing parameters | Correct tools + parameters + evidence |
| Remediation quality | No remediation | Generic advice | Specific to each vulnerability | Specific + actionable + references CVE pattern |
| False negative rate | Missed both (100% FN) | Missed one (50% FN) | Detected both, low confidence | Both detected, high confidence, zero FN |
